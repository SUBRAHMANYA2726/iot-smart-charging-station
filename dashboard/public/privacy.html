PROJECT INFORMATION

Privacy

Last updated: November 2, 2026

What the station sends

The ESP32 sends voltage, current, power, temperature, charging state, safety state, output state, Wi-Fi signal strength, and a station status message to the private ThingSpeak channel configured for this project. Start and stop requests are stored in a separate private ThingSpeak command channel.

Where the information is processed

ThingSpeak processes and stores channel entries under the account and plan used to create the channels. The Render server reads those channels, saves real telemetry history to the project's private Cloud Firestore database, and sends output requests to the separate command channel. ThingSpeak keys and Firebase service credentials stay in the server's private environment configuration. They are not sent to the browser or included in the source repository.

Dashboard sign-in

The dashboard uses a password that you configure. After sign-in, the server sets a secure, HTTP-only session cookie. Session records are kept in server memory and expire after 12 hours. They are removed when the server restarts. The password itself is not stored by the dashboard.

Browser storage and analytics

The installable web app caches its static interface so it can open without a network connection. Live readings and controls require a working connection. This project does not include third-party analytics, advertising trackers, customer counters, or review widgets.

Retention and access

ThingSpeak channel retention, account access, and deletion are managed in ThingSpeak. The Firestore collection stations/station-01/telemetry keeps the sensor history used by the graph. Anyone with access to the dashboard password can view station readings and request output changes, so keep the password private.

Contact

This is a personal project dashboard. No support email or business contact has been configured.
