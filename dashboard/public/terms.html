PROJECT INFORMATION

Terms

Last updated: November 2, 2026

Prototype use

ChargeSense is a project prototype for supervised, low-voltage demonstrations. It is not a certified charger, battery-management system, safety controller, or replacement for a device manufacturer's charging equipment.

Electrical and fire safety

Use only a regulated 5 V supply and a suitable low-voltage test load. Do not connect this prototype to mains power, an unprotected battery, a phone battery, or a load that exceeds the ratings of the wiring, sensors, MOSFET, supply, and connectors. Confirm the hardware ratings and wiring before energizing any load. Keep the demonstration attended.

Remote controls

The Start and Stop controls send a request through ThingSpeak. Delivery depends on the cloud, network, and ESP32 being available. The ESP32 is responsible for local sensor checks and can reject a Start request or disconnect the output. Do not rely on a remote request as an emergency stop. Use the physical power disconnect and hardware protection appropriate to the setup.

Configuration and access

You are responsible for using the correct ThingSpeak channel keys, protecting the dashboard password and Wi-Fi credentials, and limiting access to the dashboard. Keep the telemetry and command channels private. A public or shared channel can expose readings or allow unauthorized commands.

Operation

Cloud readings may be delayed, unavailable, or incomplete. The dashboard labels stale or unavailable data and does not invent sensor values. Check the physical station before relying on its status.
